# TripMate AI ✈️🧳

TripMate is an open-source, multimodal agentic AI travel planning system built with **LangGraph**, **Model Context Protocol (MCP)**, and **Google Gemini Flash**.

## Features Architecture
- 🛡️ **Input Guardrails**: Request validation and safety checks.
- 🤖 **Supervisor Agent**: Dynamic agent selection based on user constraints.
- 🔌 **FastMCP Tools**: Standardized APIs for weather, hotel, flight, and itinerary logic.
- 👤 **Human-in-the-Loop (HITL)**: User approval workflow before finalized outputs.
- 🎨 **Multimodal UI**: Image itinerary upload support via Gradio.
